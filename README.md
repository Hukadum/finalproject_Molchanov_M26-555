# Платформа Valuta Trade Hub (Итоговый проект)

Консольное приложение (Python-пакет), имитирующее работу валютной платформы: управление виртуальным портфелем фиатных и криптовалют, симуляция торговых сделок (Buy/Sell) и отказоустойчивое кэширование актуальных курсов в реальном времени.

**Выполнил:** Молчанов  
**Группа:** М26-555  

---

## 🛠 Ключевые особенности и архитектурные решения

* **Пакетная сборка без `src`:** Проект сконфигурирован на базе современного легковесного бэкенда `hatchling` (менеджер `uv`). Исходный код лежит напрямую в папке пакета `valutatrade_hub`, запуск выполняется командой `uv run project`.
* **Атомарность операций (ACID-like):** Запись snapshot-файла текущих курсов (`rates.json`) и журнала истории (`exchange_rates.json`) производится атомарно: данные сначала пишутся во временный файл `.tmp`, после чего атомарно заменяются через метод `os.replace()`. Это исключает порчу данных при внезапном сбое.
* **Stateless Use Cases & CLI Сессии:** Бизнес-логика (слой `core/usecases.py`) полностью очищена от хранения состояний. Текущая сессия залогиненного пользователя (`Session`) инкапсулирована исключительно внутри интерфейса командной строки `cli/interface.py`.
* **Автоматическая проверка TTL:** При вызове команды `get-rate` ядро проверяет время последнего успешного обновления локального кэша. Если оно превышает заданный TTL (300 секунд), система автоматически триггерит скрытое фоновое обновление через `RatesUpdater`.
* **Высокая отказоустойчивость:** Запросы к внешним API (CoinGecko и ExchangeRate-API) полностью изолированы. Сбой или блокировка одного из провайдеров не приводит к крашу приложения — система частично сохраняет доступные данные, логирует ошибку и продолжает работу.
* **Чистота кода (PEP8):** Весь проект успешно валидирован строгими правилами линтера `ruff` со статусом `All checks passed!`.
* **Упрощенная модель торговли:** В проекте реализована модель покупки и продажи валют без физического списания/начисления баланса USD. Доллар используется исключительно как расчетный эквивалент для вывода оценочной стоимости сделки и оценки всего портфеля пользователя.

## 📂 Структура каталогов

```text
finalproject_Molchanov_M26-555/
├── data/
│   ├── users.json          # База пользователей (Хеширование SHA-256 + соль)
│   ├── portfolios.json     # Сведения о балансах кошельков пользователей
│   ├── rates.json          # Локальный snapshot последних курсов к USD (Кэш)
│   └── exchange_rates.json # Журнал истории изменения курсов с составными UUID
├── valutatrade_hub/
│   ├── core/
│   │   ├── currencies.py   # Иерархия валют (Абстракции Currency, Fiat, Crypto)
│   │   ├── exceptions.py   # Доменные кастомные исключения платформы
│   │   ├── models.py       # Доменные модели (User, Wallet, Portfolio)
│   │   ├── usecases.py     # Чистые сценарии бизнес-логики (Stateless)
│   │   └── utils.py        # Вспомогательные валидаторы бизнес-инвариантов
│   ├── infra/
│   │   ├── database.py     # Атомарный менеджер чтения/записи JSON баз данных
│   │   └── settings.py     # Синглтон конфигурации приложения (SettingsLoader)
│   ├── parser_service/
│   │   ├── api_clients.py  # REST-клиенты интеграции с CoinGecko и ExchangeRate-API
│   │   ├── config.py       # Настройки таймаутов и маппинга токенов (ParserConfig)
│   │   ├── storage.py      # Слой записи истории и срезов котировок
│   │   ├── updater.py      # Отказоустойчивый координатор обновления кэша
│   │   └── scheduler.py    # Фоновый потоковый планировщик задач (Threading)
│   ├── cli/
│   │   └── interface.py    # Командный консольный интерфейс (PrettyTable, shlex)
│   ├── decorators.py       # Декоратор действий пользователя @log_action
│   └── logging_config.py   # Логирование (Ротация actions.log + StreamHandler консоли)
├── logs/
│   └── actions.log         # Ротируемый журнал логирования действий и ошибок
├── main.py                 # Главная точка входа приложения
└── pyproject.toml          # Конфигурация проекта и зависимостей uv/hatchling
```

## 🚀 Установка и развертывание
Склонируйте репозиторий и перейдите в корень проекта:

```bash
cd finalproject_Molchanov_M26-555
```

Синхронизируйте изолированное виртуальное окружение и зависимости (на основе pyproject.toml):

```bash
uv sync --reinstall
```

Запустите консольный интерфейс платформы:

```bash
uv run project
```

## 💻 Сценарии использования команд в CLI
После запуска приложения (>) доступны следующие команды:

* **Принудительное обновление курсов:**
`update-rates` или `update-rates --source exchangerate`

* **Просмотр курсов (с фильтрацией ТОП-2 самых дорогих криптоактивов):**
`show-rates --top 2`

* **Регистрация нового аккаунта:**
`register --username molchanov --password master`

* **Авторизация в системе:**
`login --username molchanov --password master`

* **Покупка актива в портфель (Валютный эквивалент):**
`buy --currency BTC --amount 0.05`

* **Продажа актива из портфеля:**
`sell --currency BTC --amount 0.01`

* **Просмотр портфеля (с конвертацией общей оценки в рубли):**
`show-portfolio --base RUB`

* **Просмотр прямого и обратного курсов:**
`get-rate --from USD --to RUB`

* **Выход из платформы:**
`exit`
